# Datheon_Python_Programming_Internship
Python Programming Internship at Datheon – A collection of four projects: Hangman Game, Stock Portfolio Tracker, Automated File Organizer, and Rule-Based Customer Support Chatbot.

## Internship Project Portfolio

Welcome to my Python Programming Internship Project Repository at Datheon.

This repository contains four Python programming projects developed as part of my internship. These projects demonstrate my practical understanding of Python programming, problem-solving, automation, file handling, data processing, and rule-based chatbot development.

## Internship Tasks

### Task 1: Hangman – Word Guessing Game

Description:

A Python-based interactive word guessing game in which the player attempts to guess a hidden word one letter at a time.

Key Features:

- Interactive command-line gameplay.
- Letter-by-letter word guessing.
- Tracks incorrect guesses.
- Displays the current guessed word.
- Win and lose conditions.

Technologies: Python 3

### Task 2: Stock Portfolio Performance Tracker

Description:

A Python-based stock portfolio tracking application designed to process stock-related data and generate portfolio performance summaries.

Key Features:

- Reads stock information from CSV files.
- Processes stock ticker symbols and company information.
- Handles numerical and financial data.
- Generates portfolio summary reports.
- Exports results into a CSV file.

Technologies: Python 3, CSV, OS, Decimal, Datetime

### Task 3: Automated File Organizer & Cleanup Utility

Description:

A Python-based desktop automation utility that organizes files into separate folders based on their file extensions.

Key Features:

- Automatically identifies file extensions.
- Creates category-based folders.
- Organizes documents, images, videos, archives, and code files.
- Moves files automatically.
- Handles naming collisions and file-related exceptions.

Technologies: Python 3, OS, Shutil, Pathlib

### Task 4: Rule-Based Customer Support / Product Assistant Chatbot

Description:

A rule-based interactive chatbot designed to answer customer questions using predefined frequently asked questions (FAQ) and responses.

Key Features:

- Interactive terminal-based conversation.
- Uses predefined FAQ data.
- Matches user queries with available responses.
- Provides automated customer support.
- Uses JSON for storing FAQ information.

Technologies: Python 3, JSON
